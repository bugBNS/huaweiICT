# 华为云基座部署（S-02）

锁死区域：**华北-北京四 `cn-north-4`**（控制台已在此区域；若大赛通知指定其他区域，以通知为准，三人必须同一区域）。
资源标签一律：`project=zhixun`，`env=dev`。
日常使用 **IAM 子用户**，主账号只用来开资源、看账单、发权限。

## 0. 账号与资格

- [ ] 主账号已实名
- [ ] 大赛代金券 / 预算已绑定
- [ ] 费用中心已设预算告警
- [ ] 区域已切到 `cn-north-4`（控制台右上角）

## 1. IAM 子用户（三人各一个）

控制台搜索 **统一身份认证 IAM**。

- [ ] 用户组 `zhixun-team`
- [ ] 组权限至少包含：ECS FullAccess、RDS FullAccess、DCS FullAccess、OBS Administrator、VPC FullAccess、以及码道/CodeArts 相关只读或开发权限
- [ ] 子用户：`zhixun-a`、`zhixun-b`、`zhixun-c`（开启控制台密码登录 + 编程访问）
- [ ] 三人用子用户登录验证
- [ ] Access Key 只放本机 `.env`，禁止入库、禁止发群

## 2. 网络

控制台搜索 **虚拟私有云 VPC**。

- [ ] VPC `zhixun-vpc`，网段 `192.168.0.0/16`
- [ ] 子网 `zhixun-subnet`，`192.168.1.0/24`，区域可用区记入证据
- [ ] 安全组 `zhixun-sg`
  - 入方向 SSH `22`：只放自己的公网 IP，不要 `0.0.0.0/0` 长期敞开
  - 入方向 API `8000`（或 `80`/`443`）：演示需要再开
  - 入方向 `3306`、`6379`：**仅安全组自身**，禁止对公网
  - 出方向保持默认放行

## 3. OBS 私有桶

控制台搜索 **对象存储 OBS**。

- [ ] 桶名全局唯一，例如 `zhixun-dev-<学号或随机>`
- [ ] 区域 `cn-north-4`
- [ ] 桶策略 **私有**
- [ ] 上传一个 `ping.txt`，再下载，截图
- [ ] 对象路径记入 `docs/cloud-evidence.md`

## 4. RDS for MySQL（同 VPC，无公网）

- [ ] 引擎 MySQL 8.0，单机最小规格
- [ ] 同一 VPC / 子网 / 安全组
- [ ] **不开启公网地址**
- [ ] 库名 `zhixun`，账号密码只进 `.env`
- [ ] 从 ECS 内网连通后做一次建表 / 插入 / 查询，截图

## 5. DCS Redis（同 VPC，无公网）

- [ ] 单机入门规格（128MB 或当前控制台最小）
- [ ] 同一 VPC / 子网 / 安全组
- [ ] 无公网
- [ ] 从 ECS `redis-cli` 或 Python 做 LPUSH / LPOP，截图

## 6. ECS

- [ ] Ubuntu 22.04 LTS，2 核 2G 或 2 核 4G
- [ ] 同一 VPC / 子网 / 安全组
- [ ] 系统盘 40GB
- [ ] 弹性公网 IP：演示期按需绑定，用完可解绑
- [ ] 能 SSH 登录；后续再部署 FastAPI

## 7. 码道 CodeArts

- [ ] 建项目 `智巡卫士`
- [ ] 拉 A/B/C 三人
- [ ] 每人跑一个小模块并截图（B 可用 schema 校验任务）
