## 怎么打开 drawio

1. 浏览器打开 <https://app.diagrams.net> → Open Existing Diagram → 选 `03_跨人依赖图.drawio`；
2. 或 VS Code 装 **Draw.io Integration** 扩展，直接双击；
3. 或 draw.io Desktop。

第 1 页只有 4 条跨人方向箭头（B→A、A→B、A→C、B→C），下面一张“谁等谁”清单；第 2 页才是 Issue 级 19 条跨人箭头。两张图都**不画同人内部箭头**。

第 2 页颜色含义：红色 = 关键路径；橙色 = 感知路径；紫色 = 云资格路径；橙色虚线 = P1。

- 节点里的 `[码道] [OBS] [RDS] [Redis] [ModelArts]` = 该 Issue 要用的华为云服务；
- 同一水平带 ≈ 同一波次，可并行；预览图：`03_跨人依赖图_预览.png`（简版）、`03_跨人依赖图_详版预览.png`（详版）。
