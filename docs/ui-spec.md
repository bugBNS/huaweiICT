# 智巡卫士 2.0 - UI 规范文档

## 1. 业务流程概览

> 本项目是**上传视频后的离线分析**，不是实时监控；页面/文案不得写“实时监控”。

```
视频上传 → 场景标定 → 算法分析 → 风险评估 → 策略推演 → 人工复核 → 事件归档
```

### 1.1 核心流程说明

1. **视频导入与场景标定**:用户上传仓库监控视频,标定摄像头位置、地面参考点,建立像素-米制映射
2. **分析（上传后离线处理）**:检测人员/叉车,跟踪轨迹,预测未来运动
3. **风险评估**:计算碰撞风险(TTC/PET),生成动态风险场
4. **策略推演**:反事实仿真(KEEP/减速/停车/等待),对比风险/效率
5. **人工复核**:安全员审查高风险事件,确认/驳回系统建议
6. **持续优化**:积累案例,对比模型版本,迭代策略

## 2. 页面架构

### 2.1 主导航

| 页面 | 路由 | 用途 |
|---|---|---|
| 总览仪表盘 | `/dashboard` | 风险统计、任务状态、关键指标 |
| 视频管理 | `/videos` | 上传/选择视频,查看处理历史 |
| 场景标定 | `/calibration` | 标定摄像头内外参,地面参考点 |

| 实验对比 | `/experiments` | 模型版本/策略消融对比 |
| 系统设置 | `/settings` | 阈值配置、模型版本、用户权限 |

### 2.2 布局规范

- Logo + 项目名称

**侧边栏**(宽度 240px,可折叠)
- 当前页面子功能
- 快捷操作
- 状态指示器

**主内容区**
- 工具栏(面包屑、操作按钮、过滤器)

- 底部状态栏(模型版本、坐标模式、连接状态)

## 3. 四类信息标签(视觉规范)

| 类型 | 颜色 | 图标 | 示例 |
|---|---|---|---|
| **检测事实** | 蓝色 `#1890FF` | 摄像头 | "检测到叉车 F-03,速度 2.3m/s" |
| **模型预测** | 紫色 `#722ED1` | 神经网络 | "预测 3 秒后到达冲突区(置信度 0.87)" |
| **仿真推演** | 橙色 `#FA8C16` | 实验烧杯 | "仿真:若减速至 1.0m/s,风险降低 68%" |

## 4. 核心页面详细规范

### 4.1 总览仪表盘(`/dashboard`)

**顶部 KPI 卡片**(4 列)

- 待复核事件数

## 5. 状态与异常处理

### 5.1 任务状态

| 状态 | 图标 | 颜色 | 说明 |
|---|---|---|---|
| 队列中 | ⏳ | 灰色 | 等待资源调度 |
| 分析中 | ⚙️ | 蓝色 | 算法处理中(显示进度条) |
| 已完成 | ✓ | 绿色 | 可查看结果 |
| 失败 | ✗ | 红色 | 显示错误信息 + 重试按钮 |
| 暂停 | ⏸ | 橙色 | 用户主动暂停 |

### 5.2 空状态

- **无视频**:"暂无视频,点击上传或选择示例视频"
- **无标定**:"请先标定场景,否则无法使用米制单位"
- **无风险事件**:"未检测到风险事件,系统运行正常"
- **无可行策略**:"当前场景无可行策略,建议人工介入"

### 5.3 错误状态

| 错误类型 | 提示信息 | 操作 |
|---|---|---|
| 上传失败 | "上传失败:网络超时,请重试" | 重试、取消 |
| 标定失败 | "标定失败:参考点数量不足(需至少 4 个)" | 返回编辑 |
| 分析失败 | "分析失败:视频格式不支持" | 转码、删除 |
| 连接断开 | "与服务器连接断开,正在重连..." | 自动重连 |

### 5.4 加载状态

- 列表加载:骨架屏(Skeleton)
- 3D 场景加载:进度条 + "正在加载场景..."
- 长时间操作(>3s):显示预计剩余时间

## 6. 交互规范

### 6.1 点击交互

- **高亮**:3D 场景中点击对象,高亮显示并展开详情面板
- **跳转**:点击事件 ID、任务 ID 跳转详情页
- **确认**:删除、驳回等操作需二次确认弹窗

### 6.2 时间轴联动

- 拖动时间滑块 → 3D 场景、风险场、指标面板同步更新
- 点击事件列表 → 时间轴跳转到事件发生时刻

### 6.3 快捷键(可选)

- `Space`:播放/暂停
- `←/→`:单步前进/后退(0.1s)
- `1/2/3/4`:切换策略对比视图

### 6.4 响应式适配

- 最小支持分辨率:1366×768
- 3D 场景在低配设备自动降低渲染质量
- 移动端(可选):只读查看,不支持标定/编辑

## 8. 技术约束

### 8.1 前端技术栈

- 框架:Vue 3 + TypeScript
- 构建:Vite
- 3D:Three.js(原生几何,不依赖重型库)

- UI 组件:Ant Design Vue / Element Plus

### 8.2 性能要求

- 首屏加载:<2s
- 3D 场景帧率:≥30fps(1080p)
- 时间轴拖动延迟:<100ms
- 支持浏览器:Chrome 90+、Edge 90+、Firefox 88+

### 8.3 华为云服务

- **OBS**:原始视频存储、预签名 URL 上传
- **ECS**:FastAPI 后端、Nginx 静态资源托管
- **码道**:生成工程、组件、文档草稿

## 9. 注意事项(合规与伦理)

1. **不出现自动控制表述**:系统只提供建议,不能显示"已自动减速""系统已采取措施"
2. **明确标注仿真数据**:所有仿真结果必须标注"仿真建议,需人工确认"
3. **置信度透明**:预测结果必须显示置信度,不能写成确定性语言("将发生碰撞" → "预测可能发生碰撞,置信度 0.87")
4. **未标定约束**:未标定时不显示米制数值,只显示像素坐标
5. **人工复核必选**:高风险事件必须经过人工复核,不能自动确认
6. **演示材料诚实标注**:如使用 mock 数据演示,材料需标注"演示数据"
